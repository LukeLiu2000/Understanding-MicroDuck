# Understanding-MicroDuck
Read and Understand the MicroDuck software, explain its software working process, RL algorithms and training methods, and use it as a study note and tutorial for learning RL robots.
Start from the absolute fundamentals, starting with basic experiments using tools like MuJoCo. Progress to a more advanced stage, and gain an in-depth understanding of the underlying algorithms and software architecture.
